# 公開範囲

本リポジトリに収録するのは、説明用に独立して作成した画面と架空データ、画面用の処理、そのテストです。

## 掲載する内容

- 静的な画面の構造と表示スタイル
- サンプル一覧の集計・検索・絞り込み・並び替え
- デモの起動方法とテスト方法

## 掲載しない内容

- 個人情報、認証情報、実際の口座・保有資産・取引・運用成績
- 投資判断、銘柄選定、売買条件、評価式、配分規則、バックテスト
- 実システムのコード、API 契約、DB スキーマ、AI プロンプト
- 内部構成、接続先、運用手順、ログ、設計経緯、過去の Git 履歴
- 個人の職歴や所属、第三者とのやり取り、根拠のない実績・性能の主張

サンプルの項目名・数値・推移は画面説明用です。実システムの設計・挙動・設定との対応関係はありません。

このデモ自身の表示処理はソースコードから確認できます。非公開システムの実装や判断方法は提供していません。

追加ファイルは `.gitignore` の許可リストにより既定で追跡対象外となります。掲載対象を増やす場合は、ファイル内容とコミットの作者・メール情報を確認してください。許可リストは秘密情報の自動検出を代替するものではありません。
