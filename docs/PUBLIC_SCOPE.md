# 公開範囲

## 掲載する内容

- 実システムの目的、機能、一般的な責務分離
- 採用技術と、資料で確認できた選定・設計の理由
- 銀行口座と未接続である現状、および銀行機能の閲覧専用という境界
- 短期・長期・シーン別という区分の存在と役割
- 実装から切り出した設定値アクセサと表示部品

## 掲載しない内容

- 個人情報、秘密値、実際の口座・保有資産・取引・運用成績
- 銘柄選定、売買条件、評価式、閾値、配分、具体的なシーン判定・切り替え条件
- AI プロンプト、指標の組み合わせ、詳細な状態遷移、判断用のデータ構造
- 実環境の接続先・識別子・認証設定、運用手順、ログ、バックアップ
- 内部資料の原文、開発会話、個人の職歴・所属、第三者とのやり取り、元システムの Git 履歴
- 根拠のない収益・精度・性能・開発実績の主張

公開した表示部品や設定値アクセサの処理はソースコードから確認できます。投資ロジックや非公開の接続・運用構成を再現できる資料は含めていません。

## 追加時の確認

`.gitignore` は掲載対象の許可リストです。既存ファイルへの追加内容やコミットの作者情報も確認してください。許可リストだけで機密情報の混入を防げるわけではありません。

説明と実装の範囲を区別し、未収録の機能をこのリポジトリだけで実行できるように記載しないでください。
