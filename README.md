# Project Big Tester

## 概要  
Project Big Tester は、銀行・証券の資産情報、ポートフォリオ、資産推移、システム状態を統合し、AI支援とリスク管理を組み合わせてローカル環境で運用する個人向け資産管理・自動運用プラットフォームです。

本リポジトリは、実システムから個人情報、実データ、認証情報、投資判断ロジックを除外したサニタイズ済み技術公開版です。

そのため本リポジトリは、資産情報を分かりやすく整理・可視化する操作体験を、架空データで確認するための独立した画面デモです。  
実際の口座や外部サービスに接続せず、ブラウザーだけで利用できます。

次の機能を備えています。

- **集計表示**：サンプル全体の合計値・項目数・グループ数をカードで表示
- **推移の可視化**：固定サンプルのグラフと、その数値を確認できる表を表示
- **一覧の操作**：名前による検索、グループでの絞り込み、名前順・数値順での並び替え
- **表示条件のリセット**：検索・絞り込み・並び順を初期状態に戻す
- **画面サイズへの対応**：PC・モバイルでの表示と、キーボードによるフォーム操作

※名称・数値・推移は、このデモのために作成した固定データです。実システムのソースコードや構成を再現したものではなく、投資判断・注文処理・口座連携は含みません。

## 技術スタック

以下は、このリポジトリに収録したデモの技術構成です。

| 技術 | 用途 |
| --- | --- |
| HTML | 画面構造、フォーム、表 |
| CSS | レイアウト、画面サイズへの対応、フォーカス表示 |
| JavaScript | 集計、検索、絞り込み、並び替え、画面描画 |
| SVG | サンプル値の推移グラフ |
| Node.js 標準テスト機能 | データ処理の検証（任意） |

データ処理と画面描画を分離しています。外部ライブラリー、CDN、外部 API、データベース、ビルド処理への依存はありません。

## 環境構築と使い方

### 必要な環境

- **デモの利用**：JavaScript が有効なブラウザー（Edge / Chrome など）
- **テストの実行**：標準テスト機能に対応した Node.js（任意）

デモの利用に、パッケージのインストール、アカウント登録、API キーの設定は不要です。

### 起動

1. GitHub の **Code → Download ZIP** から取得し、ZIP を展開します。Git で clone しても利用できます。
2. 展開先の `index.html` をブラウザーで開きます。
3. サンプルの集計カード・推移グラフ・一覧が表示されます。

HTML・CSS・JavaScript のファイルは同じディレクトリ構成のまま配置してください。

### 操作

1. **名前で検索**に `Asset A` などを入力すると、一致する項目を表示します。
2. **グループ**を選ぶと、検索条件と組み合わせて一覧を絞り込みます。
3. **並び順**で、名前順・値が大きい順・値が小さい順を切り替えます。
4. **条件をリセット**で初期表示に戻します。
5. **グラフの数値を確認**を開くと、推移グラフの数値を表で確認できます。

集計カードとグラフは常にサンプル全体を表示し、検索・絞り込みは一覧に適用されます。操作内容は保存されず、再読み込みすると初期状態に戻ります。

### テスト

リポジトリのルートディレクトリで実行します。追加パッケージは不要です。

```sh
node --test tests/model.test.cjs
```

集計、検索、複合条件、並び替え、該当なしの場合の処理、元データが変更されないことを確認します。

## セキュリティと運用ルール

- **架空データのみを使用**：個人情報、実際の口座情報・保有資産・取引履歴、認証情報を入力・追加しないでください。
- **データの送信・保存を行わない**：デモは同梱ファイルで動作し、外部 API への接続、アクセス解析、入力内容の永続保存を行いません。
- **ブラウザーの通信制限**：Content Security Policy の `connect-src 'none'` により、スクリプトからの通信を制限しています。
- **掲載範囲を限定**：実システムのコード、投資ロジック、内部構成、運用記録、過去の Git 履歴は追加しないでください。
- **追加前に確認**：`.gitignore` は確認済みファイルだけを追跡する許可リストです。既存ファイルの変更内容も、commit・push 前に個人情報や機密情報がないか確認してください。
- **コミット情報を確認**：作者・コミッターのメールには GitHub noreply を使用し、個人メールが履歴へ入らないようにしてください。
- **変更後の検証**：データ処理のテストと、PC・モバイルでの表示・操作確認を行ってください。
