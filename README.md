# Project Big Tester

資産情報の表示を題材とした、架空データによる独立した画面デモです。集計カード、推移グラフ、一覧の検索・絞り込み・並び替えをブラウザーで確認できます。

## 動かす

リポジトリを取得して `index.html` をブラウザーで開いてください。パッケージのインストール、アカウント登録、API キーの設定は不要です。

表示する名称・数値・推移は、このデモのために作成した固定のサンプルです。実際の資産、銘柄、取引、運用成績を表していません。データの保存や送信は行いません。

## 技術概要

- HTML / CSS / JavaScript で構成した静的な画面
- 狭い画面にも対応するレイアウトと、キーボードで操作できるフォーム
- データの集計・抽出処理と画面描画を分離
- 外部ライブラリー・CDN・外部 API に依存しない構成
- Node.js 標準のテスト機能で、検索・絞り込み・並び替え・元データの保持を確認

## ファイル

| ファイル | 内容 |
| --- | --- |
| `index.html` | 画面の構造 |
| `styles.css` | レイアウトと表示 |
| `demo-model.js` | 架空データと一覧表示用の処理 |
| `app.js` | 画面への描画と操作 |
| `tests/model.test.cjs` | データ処理のテスト |
| [公開範囲](docs/PUBLIC_SCOPE.md) | 掲載内容の境界 |

## テスト

Node.js の標準テスト機能を利用します。

```sh
node --test tests/model.test.cjs
```

このリポジトリはデモとして独立しています。実システムのソースコードや構成を再現したものではなく、投資判断・注文処理・口座連携は含みません。
